### 〔 QUÉ FUE HATSUNE MIKU BOT 〕

</div>

**Hatsune Miku Bot** fue una herramienta de automatización para WhatsApp que llevó el encanto de Miku a miles de chats. Construido sobre el núcleo de **Baileys**, funcionaba en tiempo real con módulos de IA, protección de grupos y entretenimiento.

Empezó como un proyecto personal y terminó convirtiéndose en una pequeña comunidad. Cada comando, cada sticker y cada bienvenida personalizada tuvo detrás horas de trabajo, pruebas y mucha curiosidad.

### 〔 ¿QUIERES REVIVIRLO? 〕

</div>

El código sigue disponible. Si quieres probarlo o crear tu propia versión, estos son los pasos que se usaban en **Termux**.

<details>
<summary><b>📦 Ver guía de instalación (legado)</b></summary>

<br/>

**1 —** Actualiza los paquetes base
```sh
pkg update && pkg upgrade
```

**2 —** Instala Git y Node.js
```sh
pkg install git nodejs
```

**3 —** Clona el repositorio
```sh
git clone https://github.com/Brauliovh3/HATSUNE-MIKU.git
```

**4 —** Entra al directorio
```sh
cd HATSUNE-MIKU
```

**5 —** Instala las dependencias
```sh
npm install
```

**6 —** Inicia el bot
```sh
npm start
```

> ⚡ **Termux recomendado →** [Descargar APK](https://files.catbox.moe/b6z9ml.apk)
> ⚡ Al iniciar, se generará un código de vinculación para WhatsApp Web.

> [!WARNING]
> Como el proyecto ya no se mantiene, las dependencias (especialmente Baileys) pueden estar desactualizadas. Si algo falla, será necesario actualizarlas o adaptar el código.

</details>
